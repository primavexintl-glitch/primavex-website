# PRIMAVEX INTERNATIONAL LTD --- Design System / styles.md

## 1. Design Direction

### Brand personality

Primavex should feel:

-   Premium
-   Trustworthy
-   Established
-   International
-   Natural
-   Professional
-   Calm
-   Quality-driven

Avoid making the website look like: - A generic Nigerian agricultural
marketplace - A cheap commodity listing site - A logistics-only
company - A noisy ecommerce store - A stock-template corporate website

The visual language should combine **premium international trade** with
**authentic agricultural sourcing**.

## 2. Logo-derived Colour Palette

The supplied Primavex logo uses a deep navy and warm metallic gold.

### Primary Navy

`#062852`

Use for: - Primary headings - Navigation text where appropriate -
Primary dark sections - Footer - Buttons - Brand accents

### Deep Navy

`#051A3A`

Use for: - Strong dark backgrounds - Hero overlays - Footer depth -
High-contrast UI areas

### Primary Gold

`#B78949`

Use for: - Accent lines - Small labels - Icons - Selected states -
Decorative details - Premium highlights

### Soft Gold

`#D2AE73`

Use sparingly for: - Secondary accents - Hover states - Subtle
decorative elements

### White

`#FFFFFF`

Use for: - Main page backgrounds - Cards - Navigation surfaces where
appropriate

### Warm Off-white

`#F8F6F1`

Use for: - Alternating sections - Product backgrounds - Soft editorial
blocks

### Neutral Text

`#4B5563`

Use for: - Body copy - Supporting descriptions

### Border

`#E5E0D8`

Use for: - Card borders - Inputs - Dividers

## 3. Colour Ratio

Recommended visual balance:

-   55--65% white/off-white
-   20--30% navy
-   5--10% gold
-   Remaining percentage: neutral tones and photography

Gold must remain an accent, not the dominant colour.

## 4. Typography

### Recommended primary typeface

**Manrope**

Use for: - Navigation - Body text - Buttons - Product information -
Forms - UI labels

### Recommended display typeface

**Cormorant Garamond**

Use selectively for: - Hero statements - Editorial headings - Large pull
quotes - Premium section titles

The combination should create an international, premium feel without
becoming overly decorative.

### Typography rules

-   Do not use too many font families.
-   Avoid excessive uppercase text.
-   Use sentence case for most headings.
-   Use uppercase sparingly for small eyebrow labels.
-   Keep body copy highly readable.
-   Avoid long paragraphs in major homepage sections.

-   H1: 48px
-   H2: 38px

-   H4: 22px

### Mobile

-   Display: 42px
-   H1: 38px

-   H3: 26px

## 6. Spacing System

Use an 8px base system.

Allowed spacing values:

-   8px
-   16px
-   24px
-   32px
-   40px
-   48px
-   64px
-   80px
-   96px
-   120px
-   144px

Avoid random spacing values unless necessary for optical alignment.

## 7. Layout

### Maximum content width

1440px.

### Standard content width

1200--1280px.

### Desktop page padding

64px minimum.

### Tablet

40px.

### Mobile

20px.

Use generous whitespace. The brand should feel spacious rather than
crowded.

## 8. Grid

### Desktop

12-column grid.

Recommended: - 24px gutters - 1200--1280px content area

### Tablet

8-column grid.

### Mobile

4-column grid.

## 9. Border Radius

Primary UI radius:

**10px**

Use: - Buttons - Form fields - Product cards - Image containers - Modal
surfaces

Larger editorial image blocks can use 16px if visually justified.

Avoid excessive pill-shaped UI.

## 10. Buttons

### Primary

-   Navy background
-   White text
-   10px radius
-   14--16px horizontal padding
-   Strong but not oversized

Example: **Request a Sample**

### Secondary

-   Transparent/white background
-   Navy border
-   Navy text
-   10px radius

Example: **Explore Products**

### Dark-section CTA

-   White background
-   Navy text

Use gold only as a small hover/accent treatment.

## 11. Navigation

Desktop:

-   White or very light background
-   Primavex logo
-   Products
-   How It Works
-   About
-   Contact
-   Primary CTA: Request a Sample

The navigation should feel premium and restrained.

Mobile:

-   Logo
-   Menu icon
-   Slide-down or full-screen navigation
-   Primary CTA visible inside menu

## 12. Hero Direction

The hero should be visually strong but not overloaded.

Recommended structure:

Left: - Small eyebrow: EXPORTING QUALITY FROM NIGERIA - Strong
headline - Supporting paragraph - Request a Sample - Explore Products

Right: - Large agricultural commodity image - Premium crop/detail
imagery - Optional subtle global/export visual element

Avoid generic cargo-plane imagery as the dominant hero visual. Primavex
is first a commodity supplier/exporter, not a logistics company.

## 13. Photography Direction

Use real-looking, high-quality photography.

Preferred imagery:

-   Cocoa beans
-   Sesame seeds
-   Coffee beans
-   Confirmed fourth product
-   Farmers/sourcing scenes
-   Product sorting
-   Packaging
-   Warehouse/quality inspection
-   International trade
-   Product close-ups
-   Professional buyer/supplier interaction

Photography should feel: - Authentic - Warm - Premium - Editorial -
Natural

Avoid: - Obviously artificial-looking product images - Overly saturated
agricultural stock photos - Generic handshake imagery as the main
visual - Excessive cargo/airplane imagery

## 14. Product Cards

Recommended structure:

-   Large product image
-   Product name
-   Short descriptor
-   Origin/grade information if confirmed
-   Small gold accent
-   View Product

Cards should have generous whitespace and subtle borders/shadows.

## 15. Product Detail Layout

Recommended desktop layout:

Left: - Product image gallery

Right: - Product name - Short description - Key specifications -
Availability - Sample CTA - Bulk quote CTA

Below: - Product specifications - Quality information - Packaging -
Ordering process - Shipping information - Related products

## 16. Sample-first Design Pattern

The sample concept should receive strong visual emphasis.

Possible visual treatment:

A horizontal process:

`01 Choose → 02 Sample → 03 Test → 04 Bulk Order → 05 Delivery`

Use gold numbering with navy typography.

The purpose is to visually communicate reduced buyer risk.

## 17. Trust Section

Potential design:

A large statement on the left and 3--4 proof cards on the right.

Example proof categories:

-   Quality-focused sourcing
-   Sample before bulk
-   International delivery coordination
-   Buyer-focused communication

Only use claims that the client confirms.

## 18. Forms

Input styling:

-   White background
-   1px neutral border
-   10px radius
-   16px internal padding
-   Clear label
-   Visible focus state
-   Helpful error message

Do not make forms feel like checkout pages.

## 19. Cards

Card style:

-   White or warm off-white background
-   1px neutral border
-   10px radius
-   Very subtle shadow where necessary
-   24--32px internal spacing

Avoid excessive shadows.

## 20. Sections

Use alternating: - White - Warm off-white - Navy

Gold should appear as a controlled accent.

A strong page rhythm could be:

White → Off-white → White → Navy → White → Off-white → Navy footer.

## 21. Icons

Use a simple line-icon system.

Icons should be: - Minimal - Consistent - 20--24px - Navy or gold

Avoid decorative icon overload.

## 22. Motion

Animations should be subtle:

-   Fade/slide on scroll
-   Image reveal
-   Button hover
-   Card hover
-   Navigation transitions

Do not use aggressive parallax or excessive motion.

## 23. Responsive Behaviour

Mobile must not be a compressed desktop version.

Priorities on mobile:

1.  Clear headline
2.  Product imagery
3.  Request CTA
4.  Product information
5.  Sample process
6.  Trust information
7.  Contact

Cards should stack cleanly.

Buttons can become full-width where useful.

## 24. Accessibility

Minimum requirements:

-   WCAG-conscious contrast
-   Keyboard-accessible navigation
-   Visible focus states
-   Form labels
-   Alt text
-   Logical heading hierarchy
-   Touch targets large enough for mobile

## 25. Design Principle

**Premium simplicity over visual complexity.**

The website should make an international buyer think:

> "This looks like a serious supplier I can contact."

rather than:

> "This is a flashy website."
